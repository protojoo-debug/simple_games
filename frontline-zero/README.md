# FRONTLINE: ZERO

브라우저에서 실행되는 싱글 플레이 3D 점령전 프로토타입입니다. 외부 모델과 음원을 사용하지 않고 Three.js 기본 도형, CSS HUD, Web Audio API 합성음으로 구성했습니다.

## 실행

```bash
npm install
npm run dev
```

개발 서버가 안내하는 주소를 데스크톱 브라우저에서 열고 **작전 개시**를 누르세요.

```bash
npm run build
npm run test
npm run lint
```

## 조작

- `WASD`: 이동
- `마우스`: 시점
- `좌클릭`: AX-9 펄스 카빈 사격
- `우클릭`: 정밀 조준
- `Shift`: 오버드라이브 질주
- `Space`: 점프
- `R`: 재장전
- `E`: 나노 리페어 비콘
- `F`: 임팩트 버스트
- `Q`: 전술 분석 모드(게이지 100%)
- `Tab`: 점수판
- `Esc`: 일시정지 및 설정

## 게임 규칙

중앙 에너지 노드를 점령하면 점수가 오릅니다. 적과 함께 구역에 들어가면 점령이 정지합니다. 먼저 100점을 얻거나 3분 뒤 더 높은 점수를 기록하면 승리합니다. 사망하면 5초 뒤 재투입됩니다.

## 현재 MVP 범위

- 플레이어 1명 대 상태 머신 기반 적 봇 3기
- 하나의 70m × 70m 대칭형 아레나
- 히트스캔 무기와 머리/몸통 판정
- 회복 비콘, 충격탄, 제한적 조준 보정 궁극기
- 로컬 설정 저장, 반응형 HUD, 합성 효과음
- 클라이언트 단독 판정 구조

네트워크 멀티플레이, 서버 권한 판정, 정교한 내비게이션 메시, 외부 3D 아트는 후속 범위입니다.
